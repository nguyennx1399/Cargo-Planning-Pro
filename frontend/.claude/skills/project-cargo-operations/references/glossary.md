# Glossary (project cargo)

Ref files: L = lifting-gear-and-suspension, S = ship-stability-during-lifting, P = lifting-procedure-checklist,
B = bedding-and-load-spreading, E = securing-equipment-and-welded-fittings, A = securing-arrangement-assessment.

| Term | Meaning | Ref |
|---|---|---|
| Additional tipping moment (M_add) | extra tipping moment from a big unit's rotational inertia in roll/pitch | A |
| Advanced / alternative method | CSS Annex 13 balance calculations (CS = MSL/1.5 vs MSL/1.35 with real β) | A |
| A-measure | throat thickness of a weld; fillet ≥ 6 mm assumed | E |
| BL | breaking load of a gear or securing element | L, E |
| BM / BM_lim | bending moment in a cover/pontoon/beam / moment produced by its rated uniform load | B |
| c.o.g. / c.o.s. | centre of gravity / centre of suspension (≈ hook bolt) | L |
| Condition A / B | spreading beams lying fully on deck / bridging between supports | B |
| Connecting beam | beam linking two crane hooks for a short or off-centre unit | L |
| Compression spreader | spreader pushing slings apart; needs support wires | L |
| CS | calculated strength = MSL divided by the method's safety factor | A |
| Direct securing | securing that transfers force straight into the ship structure | E |
| Down-strapping / friction loop | lashing over the top only to raise friction — banned for heavy units | E, A |
| Effective force | tension in an inclined sling, higher than its vertical hanging force | L |
| f, fx, fy | lashing efficiency factors combining angle and friction | A |
| GM*_C / KG*_C | metacentric height / KG at the worst moment of a lift, free-surface corrected | S |
| Half loop / head loop | accepted loop lashings (ends to same side / grommet over the top) | A |
| Hanging force (H) | vertical load at one lifting point | L |
| Heel φ / luffing α / hoisting δ | ship list / boom elevation / hoist wire deviation from vertical | P |
| Hoisting distance / slinging height | hatch top → max hook height / unit bottom → hook | L |
| i_p | polar radius of inertia of a unit in the tipping plane | A |
| MSL | maximum securing load of a securing element | E |
| PAL | permissible area load, t/m² | B |
| Primary / secondary suspension | slings to the hook / slings hanging from a spreader | L |
| Q | part of the crane boom mass acting at the boom top | S |
| S (ballast) | anti-heeling ballast to transfer during a lift | S |
| Silly loop / silly stopper | misleading lashing round a unit to both sides / single-fillet plate loaded across the seam — both banned | A, E |
| SWL / WLL | safe working load / working load limit of lifting gear | L |
| Stability pontoon | outrigger pontoon adding initial stability within ±3° | S |
| Virtual c.o.g. | c.o.g. raised by r to account for a tilting multi-stage rig | L |
| Vertical α / horizontal β lashing angle | angle to deck / deviation from intended direction | A |
